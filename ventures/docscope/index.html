How it works

1

Drop the package

A .docx, .xlsx or .pptx is a ZIP. The page reads the central directory and inflates each part with the browser's DecompressionStream. Stored and deflate only — the methods Office writes.

2

Read the leak report

Core properties, tracked insertions and deletions, comments, people.xml, thumbnail parts, JPEG EXIF, PNG text, and hidden sheets or slides are flagged from the XML itself.

3

Open any part

Click a name in the diagram. You get the raw XML, or a hex preview if the part is binary, plus a plain-English note on what it does and whether it is safe to send.

Why this exists

Why this exists — the repos this rides

People are generating Office files from plain text again. Docscope rides the trending repos wordcraft, gridcraft and deckcraft: builders starring those projects need to see what the package they just wrote actually contains before it is emailed.

storytold/wordcraft ★ 5,496 stars

Plain text in, .docx out. Docscope is the check on the other side: creator, last-modified-by, comments and tracked-change remnants in the file that left the tool.

storytold/gridcraft ★ 2,749 stars

Spreadsheets from structured text. Hidden sheets (state="hidden") and workbook metadata are exactly what a generated .xlsx can still carry.

storytold/deckcraft ★ 1,804 stars

Decks from text. A generated .pptx still has a thumbnail, author names, and slides with show="0" that a client can recover.

Honest limits

Honest limits — what this page does not do
  • Does not yet support PDF or DWG files. Office Open XML packages only: .docx, .xlsx, .pptx.
  • ZIP method 0 (stored) and method 8 (deflate) only — the methods Office writes. Encrypted packages are not decrypted.
  • EXIF reading covers JPEG APP1 text (ASCII tags such as Artist and DateTime) and PNG tEXt/iTXt. It does not decode every TIFF IFD type.
  • No one-click scrubbing in the free version. Inspection shows the leak; it does not rewrite the file.
  • Batch scanning is only in the Pro version. This page takes one file at a time.
  • CI and pre-commit checks are only in the Team/CI version.
  • The parsed file list is the ZIP central directory. If a part is missing from that listing, it is missing here too — we do not fill in parts the package does not have.
