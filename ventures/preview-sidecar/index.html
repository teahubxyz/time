how to use it

python3 sidecar.py watch
python3 sidecar.py watch --ports 3000,5173
python3 sidecar.py screenshot --port 3000

Python 3.9+, no installs. watch polls a bounded port list with a plain TCP connect and opens a preview the moment one answers. screenshot needs a Chromium‑family browser already on the machine.

honest limits

  • Watches a bounded candidate port list (≤200 ports), not every socket on the machine — it can't see which process owns a port.
  • Polling means a detection delay, and a port that opens and closes between polls is missed.
  • A dev server's own X‑Frame‑Options/CSP can block the preview iframe; every preview page also has a plain "open in new tab" link.
  • Screenshots need Chrome/Chromium/Edge already installed — not bundled, and a clear error if none is found.
  • Loopback only. No remote tunneling, no multi‑port orchestration — one detected port gets one preview.
