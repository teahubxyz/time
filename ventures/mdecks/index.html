How it works

Type your slides

Markdown-ish text in the editor: headings, bullets, paragraphs, --- between slides. The syntax is the stuff you already type.

Watch it set live

Every keystroke re-typesets the deck on the right. Navigate with arrow keys or swipe; the progress bar keeps your place.

Take the file with you

One button copies the deck as a single self-contained HTML file. Open it anywhere, present it offline, email it, done.
