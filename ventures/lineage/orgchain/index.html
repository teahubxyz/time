Rehearse an org on a small chain. Mint a root, give birth to children, award a badge, all as inscriptions on a private toy Bitcoin chain in this tab, with pretend money.

Test coins Private chain Lineage ↗

Rehearsal a lineage in four moves

  1. Root. Fund a wallet, then inscribe the org with metaprotocol lineage/v0 and metadata like {"lineage":"root","name":"yolopreneur"}.
  2. Birth. Inscribe a child with the root as its parent. Only the parent's holder can: the parent is spent to make the child, and the child carries the parent's ID on-chain (ord tag 3).
  3. Generations. Children can be parents too: time under the root, docscope under time, as deep as the tree goes.
  4. Badge. Inscribe a badge once, like {"lineage":"badge","skill":"launch","belt":"green"}, then mint each award as a child of it with the badge as delegate, so every award shows the same mark.

Not in this lab yet: handing an award to a seat, graduation (moving a venture's inscription to its own new root) and closing (burning a parent so no more children can be born). Those need transfers and burns, which this lab doesn't do.

Test coins only. This is a private simulation, not Bitcoin testnet or mainnet. Local-wallet keys stay in this browser, unencrypted. Inscriboor keys stay in the extension. Never load real keys or send real funds here. Nothing on Orgchain is a real org, key or badge.

Install Inscriboor

Inscriboor 0.2.4 connects on supertestnet.lol only. On Orgchain, use the local test wallet.

  1. Download and unzip Inscriboor.
  2. Open chrome://extensions (or Brave extensions).
  3. Turn on Developer mode.
  4. Choose Load unpacked and select the unzipped extension folder.
  5. Refresh this page. The button above will change from Get Inscriboor to Connect Inscriboor.

Under the hood & attribution
Orgchain is Super Testnet in lineage's clothes: the same lab and code, restyled, with a rehearsal guide on top. Its lab state lives in this browser, separate from supertestnet.lol's.
Real serialized Bitcoin transactions, Schnorr signatures and Taproot commit/reveal scripts, on a deliberately simplified local UTXO chain. No proof of work, Bitcoin consensus, peer network, public broadcast, or production custody. Synthetic local sats follow FIFO input-to-output ranges. Child creation and reinscription preserve the owned sat. Fees retire the input tail; this is not Bitcoin consensus.
Built from and inspired by Supertestnet’s testnet_generator, inscriptions-online, and vanilla-js-browser-wallet. node_faker was evaluated for future RPC compatibility.
