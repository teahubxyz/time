why this exists

The task survives the handoff.

A new agent session can read the same finishline.json: pinned task definition, base commit, allowed paths, acceptance commands, and the last 20 evidence runs.

Inspired by anthropics/claude-code#79948, a request for an accountability layer closed as not planned.

This implements a small repo-local slice of that request. It cannot provide the native, unbypassable enforcement boundary the issue asks for.

start small

Your task, your definition of done.

Keep the downloaded script in a trusted location. In a Git repository with at least one commit, create task.md:

- [ ] Build a greeting CLI
- [ ] Verify its exact output
- [ ] Document usage

Pin the task before work starts. The check below actually runs app.py and verifies its output. Review the argv in the generated card before opting into execution.

python3 /path/to/finishline.py init \
  --allow task.md --allow app.py --allow README.md \
  --check '["python3","-c","import subprocess; assert subprocess.check_output([\"python3\",\"app.py\"], text=True).strip() == \"finish line\""]'

# Observe without running commands:
python3 /path/to/finishline.py check

# After reviewing the commands:
python3 /path/to/finishline.py check --run-checks

Mark checklist items [x] as you finish them. Run again at each handoff. A prior passing run never counts as a fresh check. ANDON exits 2, WAIT exits 1, DONE exits 0.

honest limits

Evidence, with a trust boundary you supply.

  • Anyone who can edit the card, script, or checks can bypass this wrapper. It is not a sandbox or native agent enforcement.
  • Checks execute local programs with your permissions and environment. They can have side effects; there is no rollback. No automatic merge, deploy, or agent orchestration.
  • Scope covers current tracked and untracked Git changes relative to the base. Ignored files, external state, reverted changes, and the card itself are excluded.
  • DONE is only as strong as your acceptance checks. A deployment needs its own check. Command output is discarded; evidence contains exit codes and paths. Keep secrets out of task text, filenames, and argv.

Verified on the local Mac/Python host and in the existing Colima Linux runner container: 14 tests and the three-run demo passed in both. The CLI has not been tested on Fly or Boring.
