# StorySketch

Create custom illustrated bedtime stories in under a minute. Type a short story and get a 4-panel comic you can tweak and share instantly.

## What is StorySketch?

StorySketch is a free web tool that turns up to 150 words of a bedtime story into a four-panel illustrated comic. It automatically splits your text into panels, draws simple matching SVG scenes, and lets you edit any panel's text or swap its scene — the comic updates instantly. One click copies the finished comic as a PNG image, or copies embed code for that same image.

## Who is it for?

StorySketch is built for parents who want a quick custom bedtime story with pictures before lights-out. No account, no install, free to use.

## How to use it?

1. Visit [storysketch.yolopreneur.lol](https://storysketch.yolopreneur.lol/)
2. Type or paste up to 150 words of your story
3. Watch as it automatically splits into 4 illustrated panels
4. Edit any panel text or swap scenes if needed
5. Copy the comic as an image or embed code with one click

## Features

- **Free to use** - No account or payment required
- **Instant results** - See your comic update live as you type
- **Editable panels** - Change any panel's text or illustration
- **One-click sharing** - Copy the finished comic as a PNG image, or copy embed code for that image
- **Works in browser** - No installation needed

## Honest limits

- No account required means no saved stories between visits
- Only 4 panels maximum in the free version
- Basic SVG illustrations (not photorealistic)
- Stories limited to 150 words
- Copy as image needs a browser that can put a PNG on the clipboard; otherwise the same PNG downloads

## Technical Details

StorySketch is built on top of these open-source projects:
- [storytold/wordcraft](https://github.com/storytold/wordcraft) - Text processing and narrative generation
- [wheresryan22/anatomy](https://github.com/wheresryan22/anatomy) - Scene recognition and illustration mapping
