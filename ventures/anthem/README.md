# Anthem

Turn any name into a personal 8-bar theme song that plays instantly in the browser — no account, no upload, no music skill required.

## What is Anthem?

Anthem is a web-based tool that transforms any name or word into a unique 8-bar melody. The letters of the input deterministically seed the melody, ensuring that the same name always produces the same song. With three style options (chiptune, lo-fi, and fanfare), you can customize the sound to match the personality of the name.

Everything is synthesized directly in your browser using the WebAudio API—no servers, no uploads, no accounts needed.

## Who is it for?

Anthem is perfect for:
- The friend in group chats who wants to do better than 'HBD 🎉'
- Creators looking for quick, personalized audio for social media
- Anyone who enjoys playful web experiments

Instead of sending a generic GIF or emoji, type a name and send back their personal theme song.

## How to use

1. Visit [anthem.yolopreneur.lol](https://anthem.yolopreneur.lol/)
2. Type any name or word in the input field
3. Choose a musical style (chiptune, lo-fi, or fanfare)
4. Click "Play" to hear the generated theme song
5. Use "Share Link" to copy a URL that plays the song instantly for others
6. Use "Download WAV" to save the audio file

## Features

- **Name-to-Melody Engine**: Same name always produces the same song
- **Three Musical Styles**: Chiptune, lo-fi, and fanfare remixes
- **Animated Title Card**: Visual representation of your theme
- **Instant Sharing**: Copy a link that plays the song when opened
- **WAV Download**: Save your creations as audio files
- **No Uploads Required**: Everything runs locally in your browser
- **No Account Needed**: Start creating immediately

## Honest Limits

- Only generates 8-bar melodies
- Limited to three musical styles
- No custom instruments or effects
- No lyrics or vocals
- Basic WAV export only

## Technical Details

Anthem uses the WebAudio API to synthesize audio directly in your browser. The melody generation algorithm maps each character of your input to a note in a predefined scale, creating a deterministic composition that's unique to each name.
